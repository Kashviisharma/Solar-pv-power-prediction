# Grafana Dashboard Setup

This directory contains the Grafana dashboard configuration for visualizing solar PV predictions.

## Dashboard Overview

The dashboard displays:
- Actual vs Predicted PV Power over time
- Current Solar Irradiance (gauge)
- Prediction Error over time
- Current PV Output (gauge)
- Environmental Temperatures (ambient and panel)
- Model Information

## Data Source

The dashboard expects time-series data from `data/processed/predictions_time_series.csv` generated by the simulator script.

### CSV Schema

The CSV file contains the following columns:
- `timestamp`: UTC timestamp
- `irradiance`: Solar irradiance in W/m²
- `ambient_temperature`: Ambient temperature in °C
- `panel_temperature`: Panel temperature in °C
- `wind_speed`: Wind speed in m/s
- `actual_power_kw`: Actual measured power in kW
- `predicted_power_kw`: Model-predicted power in kW
- `prediction_error_kw`: Difference between actual and predicted (kW)

## Setup Options

### Option 1: CSV Datasource Plugin (Recommended for Development)

1. Install the CSV datasource plugin:
   ```bash
   grafana-cli plugins install frser-simpod-json-datasource
   ```
   Or use the built-in CSV support in Grafana 9.0+

2. Configure the CSV datasource:
   - URL: path to `data/processed/predictions_time_series.csv`
   - Format: CSV

3. Import the dashboard:
   - Go to Dashboards → Import
   - Upload `dashboard.json`
   - Select the CSV datasource

### Option 2: PostgreSQL (Recommended for Production)

For production use, import the CSV data into PostgreSQL:

1. Start PostgreSQL (using Docker Compose):
   ```bash
   docker-compose up -d postgres
   ```

2. Create table and import data:
   ```sql
   CREATE TABLE predictions_time_series (
     timestamp TIMESTAMP PRIMARY KEY,
     irradiance FLOAT,
     ambient_temperature FLOAT,
     panel_temperature FLOAT,
     wind_speed FLOAT,
     actual_power_kw FLOAT,
     predicted_power_kw FLOAT,
     prediction_error_kw FLOAT
   );
   
   COPY predictions_time_series FROM '/data/predictions_time_series.csv' DELIMITER ',' CSV HEADER;
   ```

3. Configure PostgreSQL datasource in Grafana
4. Import the dashboard

### Option 3: Simple Python Dashboard (Alternative)

For quick visualization without Grafana, use the provided Python script:

```bash
python scripts/visualize_predictions.py
```

This will open an interactive matplotlib dashboard.

## Running Grafana with Docker

```bash
# Start Grafana
docker-compose up -d grafana

# Access at http://localhost:3000
# Default credentials: admin/admin
```

## Dashboard JSON

The `dashboard.json` file is configured for PostgreSQL. To use with CSV, modify the datasource queries to use the CSV datasource type.

## Notes

- The dashboard auto-refreshes every 5 seconds
- Time range defaults to "Last 1 hour"
- All panels are configured with appropriate units (kW, W/m², °C, m/s)
